# Frontend User Flow

- User come to website
  - Cookies T&Cs
- Check if the website is latest version via version control
- Check if user is
  - New User
  - Registered User
- For Registered User - Check if there is an abandoned cart
  - If yes – check for delivery/pickup date
    - Ask user to update delivery date
    - The slider should show all details such as delivery address, order type – pickup / delivery, store, etc
  - Once user updates delivery details – update cart as well – pricing, availability (if the product is not available – show that this product is not available atm)
- New User – show default products
  - Once user adds 1st product – ask user details same as in harrisfarm
  - Highlight that if the delivery/pickup address is changed – the cart will be reset.
  - Then system will allocate the store based on delivery or pickup details
